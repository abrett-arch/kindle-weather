Set up this phone
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → kindle-messages.
  3. Permissions: Contents → Read and write. Expiration: up to you (you'll repeat this when it expires).
  4. Paste the token below. It's kept only in this app on this phone. If you added the page to your home screen, paste it there, inside the home-screen app.
